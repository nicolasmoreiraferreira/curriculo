# Carta de apresentação

Três versões do mesmo texto, para situações diferentes:

| Versão | Quando usar |
| --- | --- |
| **Completa** | Campo de texto grande, candidatura por e-mail, ou quando pedem "carta de apresentação" sem limite |
| **Curta** | Formulário com limite de caracteres, ou campo que pede só um resumo |
| **Em inglês** | Vaga internacional ou que pede o texto em inglês |

Substitua os trechos entre `[colchetes]`. Se me disser qual é a vaga, eu ajusto o
texto para ela — cada carta rende mais quando cita a empresa e o problema que ela
resolve.
