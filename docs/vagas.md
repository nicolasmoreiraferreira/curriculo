# Onde se candidatar

Levantamento feito em setembro de 2026, considerando o perfil: **front-end e full
stack, React/TypeScript, primeira oportunidade profissional, inglês básico**.

## 1. Globant — a vaga que você viu não serve

**`.Net Developer - Brazil`** (a que você mandou): é nível **pleno-sênior** e pede
ASP.NET, C#, LINQ, Entity Framework, SQL Server, SSRS/SSIS, microsserviços,
containers e **inglês avançado**. Nenhum desses requisitos centrais está na sua
stack. O único item que você atende é o "plus": familiaridade com React.

Vale saber o que a Globant tem no Brasil hoje (consultado no site de vagas):

| Vaga | Nível | Por que serve ou não |
| --- | --- | --- |
| Entry-Level Data Engineer - São Paulo | Entrada | Pede Power BI, Azure (Data Factory, Databricks, Synapse), ETL/ELT e Python/C#/Java. Não é front-end, mas é a única de entrada aberta |
| Tech Project Manager - São Paulo | — | Gestão de projeto, não desenvolvimento |
| Senior Cybersecurity Engineer - São Paulo | Sênior | Fora do seu perfil |
| SAP Developer Tech / SAP Integration / SAP FI / SAP MM | Vários | SAP, com requisitos específicos (um deles exige japonês fluente) |
| Java Developer - Expert-Level | Expert | Fora do perfil |

**Conclusão honesta:** a Globant Brasil não tem vaga de front-end React aberta
neste momento no nível de entrada. Se quiser insistir na Globant, a **Entry-Level
Data Engineer** é a única porta de entrada — mas exigiria estudar Azure e Power BI
antes, e não é o caminho natural do seu portfólio.

A Globant também tem um **programa de entrada** ("U-Grow", com foco em formação de
júnior) e vagas de trainee que não aparecem sempre no site. Vale acompanhar
`career.globant.com` e o LinkedIn deles.

O mercado brasileiro de React tem cerca de **30% das vagas em nível júnior** e a
maioria exige React + TypeScript, que é exatamente o que o Estados demonstra.
Estas são as plataformas com vagas abertas agora:
